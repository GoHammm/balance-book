# Balance Book

A study app for simultaneous equations and geometry. Every topic has a beginner lesson, endless practice questions with each step explained, timed mock tests, and achievements to track progress.

## What's inside

**Equations**
- Stage 1, linear simultaneous equations: elimination, substitution, word problems
- Stage 2, non-linear simultaneous equations: line and curve, line and circle, sum and product. Unlocks after scoring 80% on the linear mock.

**Geometry**
- Stage 1, shapes and trigonometry: angle rules, area and perimeter, Pythagoras, SOH CAH TOA, sine and cosine rules
- Stage 2, coordinate geometry: distance and midpoint, gradient and y = mx + c, parallel and perpendicular lines, circles. Unlocks after scoring 80% on the shapes and trig mock.

Progress is saved in the browser on each device.

## Running it

It's a single `index.html` file with no build step. Open it in a browser, or deploy the repo to any static host such as Vercel.
